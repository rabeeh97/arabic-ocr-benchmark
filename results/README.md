# results/

One folder per benchmark run, named `<UTC timestamp>` (e.g. `20260901T134500Z`).

```
results/<run_id>/
  run_config.snapshot.yaml   # exactly what was run
  predictions.jsonl          # one row per (line, model): raw + cleaned output, latency, tokens, cost, error
  scores.jsonl               # one row per (line, model): CER/WER (raw, light, diac_insensitive), diacritic P/R/F1
  summary.csv                # per (model, dataset): micro/macro CER/WER, exact-match, refusal rate, cost
  summary.md                 # the headline table
results/leaderboard.html     # all runs combined — the shareable artifact (regenerated by scripts/make_leaderboard.py)
results/leaderboard.json     # same, machine-readable
```

Run dirs are committed to the repo — that is how results come back from Colab
(the notebooks `git push` them). Only `results/_cache/` (the local resume cache)
is git-ignored.

Regenerate the leaderboard after adding runs:

```bash
uv run python scripts/make_leaderboard.py results -o results/leaderboard.html
```
