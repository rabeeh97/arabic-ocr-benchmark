Checklist 2.6 (map P-L3). Share of each panel test set's PAW tokens covered by the N most frequent PAW types of a reference text. PAW = letters up to and including a right-joining letter or ء; dotless = position-aware rasm. Bands: 95 % cluster bootstrap (pages for NAKBA/RASAM, identical texts for KHATT, lines for Muharaf).

Decision

(fixed before the run; vocabulary option (3) "shape BPE up to PAW-sized units" of shape-programme step 5):
  KEEP PAW-level units     if an arwiki-ranked dotless-PAW inventory of <= 8,000 types covers >= 99 % of PAW tokens on every
                           panel test set (lower 95 % bound);
  PAW + sub-PAW fallback   if <= 8,000 types reach 95 % (lower bound) everywhere but not 99 %;
  DROP PAW-level units     otherwise.
