# Data licences and image provenance

Our **code** is MIT (`LICENSE`); our **own written results** are CC BY 4.0
(`LICENSE-RESULTS`). **Dataset images are not ours.** Every dataset keeps its
own licence, summarised here. This repository never contains a dataset in
bulk (`data/` is git-ignored); it contains only a small number of line crops
inside generated report pages and sample files.

## Datasets whose crops may appear in this repository

| Dataset | Source | Licence | Notes |
|---|---|---|---|
| Muharaf (`muharaf_lines`, `kitab_muharaf`) | HF `aamijar/muharaf-public` | **CC BY-NC-SA 4.0** | Crops are *adapted* (resized / cropped). They stay CC BY-NC-SA 4.0: attribution, **non-commercial**, share-alike. Cite the Muharaf paper (NeurIPS 2024). |
| NAKBA (`nakba_lines`, `nakba_blind`) | HF `U4RASD/omar-al-saleh-manuscripts-segments` | **CC BY 4.0** | Attribution required (NAKBA NLP 2026 shared task data). |
| RASAM 1 / 2 | HF `calfa-ai/RASAM-1`, `RASAM-2` | **Apache-2.0** | Attribution and licence notice. |
| AraMS (`arams_htr`) | Zenodo 10.5281/zenodo.21499649 | **CC BY-NC-SA 4.0** | As Muharaf. |
| Synthetic renders | generated by this repo | MIT / CC BY 4.0 | Rendered text, no third-party images. |

Any file in this repository that embeds Muharaf or AraMS crops is therefore
**partly CC BY-NC-SA 4.0** (the crops); the rest of that file remains under
`LICENSE-RESULTS`. Do not use those crops commercially.

## Datasets we use but do NOT redistribute

Their licences are restricted or unstated, so **no image from them is committed**.
Reproduce locally with `src/arabic_ocr_bench/datasets` after obtaining the data
under its own terms.

| Dataset | Why not redistributed |
|---|---|
| KHATT (incl. Online-KHATT, via the KITAB-Bench mirror) | Original KFUPM terms are research use on request; the mirror's MIT tag does not relicense it. |
| KITAB-Bench subsets: Hindawi, HistoryAr, HistoricalBooks, PATS-OCR, ADAB, ISI-PPT, EvArEST, ArabicOCR | No licence stated on the dataset pages. |
| APTI | Redistribution terms not confirmed. |
| SARD (CC BY-NC-ND 4.0), MADCAT (LDC), Muharaf-restricted (proprietary) | Used/considered only locally, if at all. |

In generated pages (galleries, atlases, leaderboard) those images appear as a
1x1 grey placeholder. Re-run the build script listed in `scripts/README.md` on a
machine that has the data to regenerate them for **private** use.
