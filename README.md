# arabic-ocr-bench

A reproducible benchmark for **Arabic cursive script recognition** (handwritten
text recognition / HTR). It measures how well modern LLMs / vision-language
models — and classical OCR engines — transcribe cursive handwritten Arabic, on
the *same* data with the *same* metrics.

**Hypothesis under test:** general multimodal LLMs are overtaking traditional
HTR pipelines for cursive Arabic, and cheap fine-tuning could close the rest of
the gap.

## Status

Phase 1 — thin vertical slice. Line-level track on the Muharaf dataset, one
model, raw + Arabic-normalized CER/WER, latency and cost.

## Quickstart (local)

```bash
source env.sh                       # pins ALL caches (uv, HF, pip, torch) to this drive
uv sync --extra dev                 # core + test deps
uv run python -m pytest             # unit tests (metrics, normalization, runner)

# smoke run: 15 Muharaf test lines against the zero-cost mock models
uv run bench run --config configs/run.yaml --report
```

To run real models locally:

```bash
uv sync --extra dev --extra local   # adds torch / transformers for local models
cp .env.example .env                 # add API keys for hosted models
```

## Quickstart (Google Colab) — recommended for the first benchmark

**v1 walkthrough: [`docs/first-benchmark-runbook.md`](docs/first-benchmark-runbook.md)** —
one local model (`qari-ocr-0.2`) on Colab's free T4, no paid API, from opening the
notebook to publishing the leaderboard artifact.

See [`notebooks/README.md`](notebooks/README.md) for per-notebook setup. The four notebooks:

- `notebooks/00_reference_gemini_pipeline.ipynb` — the team's original prototype (kept for reference)

- `notebooks/01_colab_local_models.ipynb` — Qari-OCR / Qwen2.5-VL / PaliGemma-Arabic on a GPU
- `notebooks/02_colab_hosted_apis.ipynb` — Gemini / OpenAI / Claude via API keys
- `notebooks/03_analysis.ipynb` — leaderboard + worst-error browser

They are generated by `scripts/build_notebooks.py` (edit there, re-run, don't hand-edit the `.ipynb`).

## Metrics

- **CER / WER** — raw (exact) and Arabic-normalized (light + diacritics-insensitive profiles)
- **Diacritic accuracy** — precision / recall / F1 over harakat
- **Aggregation** — micro (corpus-weighted) and macro (per-sample), size-weighted across datasets
- **Operational** — latency, token counts, USD cost, refusal rate
